# Insurance ML

Exploratory Data Analysis and feature engineering on an insurance dataset using Python.

## Project Overview

This project explores an insurance dataset to understand the data, identify patterns, handle missing values, visualize relationships, and prepare features for machine learning.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Steps Covered

* Data loading and understanding
* Data cleaning
* Exploratory Data Analysis (EDA)
* Data visualization
* Correlation analysis
* Feature engineering
* Feature scaling
* Basic statistical analysis

## Project Files

* `eda_featureenineering.ipynb` — Jupyter Notebook containing the analysis and feature engineering.

## Dataset

The project uses an insurance dataset for learning and analysis purposes.
